# PySide Desktop UI

Recommended desktop UI for Photo Restorer.

Run from repository root:

```bash
pip install -e '.[desktop]'
photo-restorer-ui
```

This UI is focused on the crop workbench:

- Open scan image
- Tune detection thresholds
- Rerun detection
- Drag four corner points
- Add manual four-point region when detection misses a photo
- Crop selected photo
- Enable/disable pipeline steps before running
